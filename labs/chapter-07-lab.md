# Chapter 7 Lab: Computer Vision and Image Generation in Foundry

**Estimated time:** 20 minutes

## Exercise

Foundry Computer Vision lab: (1) Upload retail shelf image, use object detection to count products and identify misplaced items. (2) Use OCR to extract text from a scanned receipt including printed text and table structure. (3) Test image classification on 5 photos (correctly classify each into 'indoor', 'outdoor', 'food', etc.). (4) Generate 3 images from text prompts using Foundry image generation model, observe how prompt specificity affects output.

## Key takeaway

Computer vision tasks include image classification (one label per image), object detection (multiple objects with locations), and OCR (text extraction), while facial detection provides face location and attributes but facial identification (determining who someone is) faces strict privacy regulations—the exam tests which capability fits scenarios involving counting objects, categorizing images, or extracting text.
