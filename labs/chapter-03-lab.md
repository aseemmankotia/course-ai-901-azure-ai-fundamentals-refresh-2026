# Chapter 3 Lab: How Generative AI Models Work

**Estimated time:** 18 minutes

## Exercise

Microsoft Foundry Playground: deploy GPT-3.5-turbo, test prompts with different temperature settings (0.0 vs 1.0), observe token counts, intentionally trigger hallucination by asking about non-existent events, then add grounding by providing reference text in the prompt

## Key takeaway

Generative AI models process text as tokens (units affecting cost and limits), can hallucinate false information requiring grounding with real data, and come in LLM (powerful, slower, costly) and SLM (specialized, faster, cheaper) variants—the exam tests when to choose each and how to mitigate hallucination.
