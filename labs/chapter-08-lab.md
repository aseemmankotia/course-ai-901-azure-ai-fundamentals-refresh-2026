# Chapter 8 Lab: Information Extraction with Azure Content Understanding

**Estimated time:** 18 minutes

## Exercise

Azure Content Understanding lab in Foundry portal: (1) Upload a sample invoice, use pre-built invoice model to extract vendor, total, tax, line items. (2) Upload a receipt, extract merchant, date, items, total. (3) Test layout analysis on a form with tables and checkboxes. (4) Review extracted JSON output showing field names, values, confidence scores, bounding box coordinates.

## Key takeaway

Azure Content Understanding extracts structured data (field names and values) from documents like invoices, receipts, and forms using pre-built models for common types or custom models for specialized documents—the exam tests when to use Content Understanding (structured extraction) versus OCR (text reading) or NLP (language analysis).
