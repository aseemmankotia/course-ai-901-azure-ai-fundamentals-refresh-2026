# Chapter 6 Lab: Text and Speech AI with Foundry Tools

**Estimated time:** 18 minutes

## Exercise

Foundry Tools exploration: (1) Analyze sample customer reviews with sentiment analysis, observe confidence scores. (2) Extract key phrases from a product description. (3) Identify entities (product names, prices) in an invoice. (4) Translate a support message from Spanish to English. (5) Test speech-to-text with a 30-second audio clip. (6) Generate audio from text using text-to-speech with two different voices.

## Key takeaway

Foundry Tools provides pre-built capabilities for text analytics (sentiment scores, key phrase topics, structured entity extraction) and speech processing (audio-to-text transcription, text-to-audio synthesis)—the exam tests which tool fits scenarios like 'analyze customer feedback tone' (sentiment), 'identify article themes' (key phrases), or 'make audio searchable' (speech-to-text).
