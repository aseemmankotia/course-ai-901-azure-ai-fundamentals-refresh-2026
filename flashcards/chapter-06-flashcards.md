## Chapter 6: Text and Speech AI with Foundry Tools — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Sentiment analysis confidence score range and meaning? | 0.0 to 1.0. Represents model's confidence in sentiment classification (positive/negative/neutral/mixed). 0.92 = 92% confident in classification. Exam tip: Score is confidence, not percentage of positive words. |
| 2 | Four sentiment categories in Azure AI Language? | Positive, negative, neutral, mixed. Each includes confidence score 0.0-1.0. Exam tip: 'Mixed' means document contains both positive AND negative sentiment (not neutral). |
| 3 | Key phrase extraction vs entity recognition: what's the difference? | Key phrases: main topics/themes (e.g., 'customer support', 'product quality'). Entities: structured data with types (person names, locations, dates, organizations, quantities). Exam tip: Use entities for extracting specific typed data, key phrases for identifying discussion topics. |
| 4 | When to use language detection vs translation? | Language detection: identify language only (routing, filtering). Translation: convert between languages. Exam tip: If requirement says 'no translation needed' or 'route to language-specific pipeline'—use detection only. Don't over-engineer. |
| 5 | How many languages does Azure Translator support? | 100+ languages. Exam tip: Translator is separate from Language service. If question mentions '100+ languages' in translation context, it's likely testing Translator service knowledge. |
| 6 | Speech-to-text vs text-to-speech: which direction? | Speech-to-text: audio → text (transcription). Text-to-speech: text → audio (synthesis/narration). Exam tip: 'Transcribe phone calls'=speech-to-text. 'Generate audio narration'=text-to-speech. Direction matters! |
| 7 | Real-time transcription vs batch transcription? | Real-time: live audio streaming, immediate text output during conversation. Batch: pre-recorded audio files processed after recording. Exam tip: 'Live calls', 'as conversation happens'=real-time. 'Recorded files', 'post-call analysis'=batch. |
| 8 | What are neural voices in text-to-speech? | High-quality, natural-sounding synthetic voices using deep neural networks. Customizable (male/female, accents, languages). Exam tip: If question mentions 'natural-sounding' or 'multiple voice options'—neural voices. |
| 9 | Entity recognition: what types of entities can be extracted? | Person names, locations, dates, organizations, quantities (numbers/amounts), emails, URLs, phone numbers. Exam tip: If requirement lists 'extract company names, dates, amounts'—entity recognition, not key phrase extraction. |
| 10 | Azure AI Foundry Tools advantage over custom models? | Pre-built components for common tasks (sentiment, key phrase, entity). No training data needed, work out-of-box, faster development. Exam tip: Use Foundry Tools for standard scenarios. Custom models for specialized domains only. |
| 11 | Sentiment analysis output for a document? | Overall sentiment (positive/negative/neutral/mixed) + confidence score per category + per-sentence sentiment. Exam tip: Document-level sentiment may be 'mixed' even if most sentences are positive—exam tests understanding of mixed vs neutral. |
| 12 | Language detection: when should it run BEFORE translation? | When source language is unknown and you need to route/filter based on language, or optimize costs by skipping translation for target language. Exam tip: 'Articles in multiple languages, make available in English'—detect first, translate only non-English articles. |
