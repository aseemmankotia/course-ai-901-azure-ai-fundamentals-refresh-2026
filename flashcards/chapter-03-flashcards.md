## Chapter 3: How Generative AI Models Work — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What is a token in the context of LLMs? | A token is a unit of text (roughly 4 characters or 0.75 words in English). LLMs process and bill by tokens. Example: 'Hello world' = 2 tokens. Exam tip: Token limits apply to prompt + completion combined, not separately. |
| 2 | GPT-4 vs GPT-3.5-turbo: When to use which? | GPT-4: Complex reasoning, multi-step problems, nuanced understanding. Higher cost, higher latency. GPT-3.5-turbo: Simple tasks, high volume, speed-critical, cost-sensitive. Exam tip: Choose 3.5 unless complexity explicitly requires GPT-4. |
| 3 | What is hallucination in generative AI? | Generating false or fabricated information presented as fact (e.g., fake citations, non-existent statistics). Exam tip: Solution is grounding with retrieval (RAG), not just using a larger model or adjusting temperature. |
| 4 | When should you use an SLM instead of an LLM? | SLM (Small Language Model) when: specialized domain, low latency critical, cost-sensitive, can deploy locally, simpler tasks. Exam tip: High-volume + speed + cost optimization = SLM. Complex reasoning = LLM. |
| 5 | Temperature parameter: 0 vs 0.7 vs 1.0? | 0 = deterministic, consistent, factual tasks. 0.7 = balanced creativity/consistency (default). 1.0+ = maximum creativity, randomness. Exam tip: Factual/data = low (0-0.3). Creative content = medium-high (0.7-0.9). |
| 6 | What are embeddings used for? | Converting text to numeric vectors that capture semantic meaning. Used for: similarity search, clustering, retrieval in RAG systems. Exam tip: Embeddings enable finding 'similar' content even with different words. |
| 7 | What is the purpose of a system message in a prompt? | Sets persistent behavioral context and role for the conversation (e.g., 'You are a Python expert'). Applies to all subsequent user messages. Exam tip: System message = behavior/role. User message = actual request/data. |
| 8 | What is grounding in generative AI? | Providing the model with specific data/documents as context to base responses on, preventing hallucination. Implemented via RAG (Retrieval-Augmented Generation). Exam tip: Current data + factual accuracy = need grounding. |
| 9 | max_tokens parameter - what does it control? | Maximum number of tokens in the completion (output), NOT input. Total tokens = input + output, must stay within model's context limit. Exam tip: Model limit 8192, prompt 1000 → max_tokens cannot exceed 7192. |
| 10 | Context window - what is it? | Maximum total tokens (input prompt + output completion) a model can process in one request. Varies by model: GPT-3.5-turbo (4K-16K), GPT-4 (8K-128K). Exam tip: Larger context = can process longer documents but doesn't mean unlimited output. |
| 11 | What limitation requires implementing RAG? | Lack of real-time/current data (models have training cutoff dates) and need for factual grounding. RAG retrieves current documents to provide as context. Exam tip: Monthly updates, current data, no hallucination = RAG needed. |
| 12 | Primary use cases for generative AI models? | Content generation, summarization, translation, question answering, code completion, conversational agents. Exam tip: Match scenario to use case - FAQ = Q&A, blog = generation, multilingual = translation, etc. |
