## Chapter 8: Information Extraction with Azure Content Understanding — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Azure AI Document Intelligence pre-built receipt model: what fields does it extract? | Merchant name, merchant address, merchant phone, transaction date, transaction time, total, subtotal, tax, tip, line items (description, quantity, price). Exam tip: Use receipt model when extracting expense/reimbursement data from receipts—don't build custom parser. |
| 2 | When should you train a CUSTOM Azure AI Document Intelligence model instead of using pre-built models? | When documents have organization-specific layouts or fields not covered by pre-built models (invoice, receipt, ID, business card, W-2, 1099). Need 5+ labeled examples minimum. Exam tip: Pre-built first; custom only when pre-built doesn't fit your specific document type. |
| 3 | Azure AI Document Intelligence confidence score: what does 0.0-1.0 represent? | Model's certainty in extraction accuracy (0.0 = no confidence, 1.0 = maximum confidence). Low confidence (<0.85 typical threshold) should trigger human review. Each extracted field has its own score. Exam tip: Confidence scores help build human-in-the-loop workflows for accuracy-critical scenarios. |
| 4 | Difference: Azure AI Document Intelligence vs Azure AI Vision OCR | OCR: reads text from images, returns text + bounding boxes, NO structure/labels. Document Intelligence: extracts STRUCTURED fields with labels (e.g., 'Invoice Number: X'), understands document layout (tables, key-value pairs, checkboxes). Exam tip: Form/document extraction = Document Intelligence. Just reading text = OCR. |
| 5 | Azure AI Document Intelligence pre-built ID document model: what ID types and fields? | Types: driver's licenses, passports, ID cards, residence permits. Fields: first/last name, DOB, document number, address, expiration date, sex, country/region, machine-readable zone. Exam tip: Use for identity verification scenarios—handles global ID formats. |
| 6 | Azure AI Document Intelligence layout analysis: what does it extract? | Tables (with rows/columns preserved), selection marks (checkboxes/radio buttons), text lines with reading order, page structure, bounding boxes. Returns spatial information. Exam tip: Use when you need table data or checkbox states extracted with structure intact. |
| 7 | What is key-value pair extraction in Azure AI Document Intelligence? | Identifying field labels and their associated values (e.g., 'Invoice Number: 12345' → key='Invoice Number', value='12345'). Model finds semantic relationships between labels and values on forms. Exam tip: Key-value pairs are the core output for form extraction—structured, labeled data. |
| 8 | Azure AI Document Intelligence pre-built invoice model: what fields? | Vendor name/address, customer name/address, invoice ID, invoice date, due date, total, subtotal, tax, line items (description, quantity, unit price, amount), purchase order number. Exam tip: Use for AP automation scenarios—extracts full invoice structure including line items. |
| 9 | Minimum number of labeled documents needed to train a custom Azure AI Document Intelligence model? | 5 labeled examples minimum. Recommended: 15-20 for better accuracy. Can improve model by adding more labeled samples over time. Exam tip: If scenario mentions <5 examples, cannot train custom model—use pre-built or collect more samples. |
| 10 | Difference: Azure AI Document Intelligence vs Azure AI Language service for document processing | Document Intelligence: extracts structured DOCUMENT fields/layout (invoice total, receipt merchant, table cells). Language: analyzes TEXT CONTENT (sentiment, key phrases, entities, language). Exam tip: Document structure/forms = Document Intelligence. Language analysis = Language service. Different purposes. |
| 11 | Azure AI Document Intelligence pre-built business card model: what fields? | Contact names, job titles, company names, departments, addresses, emails, websites, phone numbers (mobile/work/fax). Handles varied layouts/designs. Exam tip: Use for digitizing contact info from business cards—no training needed. |
| 12 | What accuracy improvement should you implement when Azure AI Document Intelligence returns low confidence scores (<0.85)? | Implement human-in-the-loop review: route low-confidence extractions to human reviewers for verification/correction. Use verified data to retrain custom models (if applicable). Set confidence thresholds based on risk tolerance. Exam tip: Low confidence = human review workflow, not automatic rejection. |
