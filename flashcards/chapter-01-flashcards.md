## Chapter 1: Common AI Workloads and Business Scenarios — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Computer vision workload that identifies and locates multiple objects in a single image with bounding boxes and confidence scores | Object detection. Exam tip: Use for counting items (inventory, people), not for identifying what type of scene it is (that's classification). Returns coordinates + label + confidence for each object. |
| 2 | Difference between OCR and document intelligence | OCR extracts text only. Document intelligence extracts text + understands layout + identifies entities + recognizes forms/tables. Exam scenario: reading invoices/receipts = document intelligence, reading a sign = OCR. |
| 3 | NLP workload that assigns predefined categories like 'positive', 'negative', 'neutral' to text | Sentiment analysis. Returns numeric score 0-1 (0=negative, 1=positive). Exam tip: Used for analyzing reviews, social media, feedback—not for extracting facts or entities. |
| 4 | Which NLP workload extracts people names, locations, dates, organizations from text? | Entity recognition (NER). Exam tip: Identifies what things are mentioned, not how positive/negative the text is (that's sentiment). Common entities: Person, Location, DateTime, Organization, Quantity. |
| 5 | AI agent vs chat application—key distinguishing capability | Agent: autonomous multi-step task completion with tool use and decision-making. Chat: conversational interface for back-and-forth dialogue. Exam scenario: 'automate testing and debugging' = agent, 'customer Q&A' = chat. |
| 6 | Computer vision workload for identifying specific individuals by facial features | Facial recognition (face identification). Exam tip: Different from face detection (just finds faces) and face verification (confirms if two faces match). Use case: security access, not age estimation. |
| 7 | Speech workload that converts audio in one language directly to text in another language | Speech translation. Single-step workload optimized for real-time use. Exam tip: More efficient than speech-to-text → translate → text-to-speech for live scenarios like conferences. |
| 8 | Generative AI workload types tested on AI-900 | Text generation, image generation, code completion. Exam tip: All create NEW content from prompts. Not for analyzing existing content (that's classification, detection, NLP). |
| 9 | Scenario: counting products on shelves from camera images—which CV workload? | Object detection. Exam tip: Key word 'counting multiple' = object detection. If question asks to identify if image shows a product vs non-product = classification. |
| 10 | NLP workload that identifies main topics or important phrases in a document | Key phrase extraction. Returns list of significant phrases. Exam tip: Use for document summarization, tagging, not for determining sentiment or extracting specific entity types. |
| 11 | Scenario: extracting patient names and medication dosages from handwritten doctor notes—which workload? | Document intelligence (with entity extraction). Exam tip: Handwritten + structured extraction = document intelligence. If only reading printed text = OCR. If just categorizing document type = classification. |
| 12 | Text-to-speech vs speech-to-text—which direction is which? | Speech-to-text: audio → text (transcription). Text-to-speech: text → audio (synthesis/voice). Exam tip: TTL is 'Text To Voice'. STT is 'Sound To Text'. Think of the T position. |
