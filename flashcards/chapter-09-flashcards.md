## Chapter 9: Full Exam Simulation and Test-Taking Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | AI-901 exam: How many questions and how much active time? | 40-60 questions, 45 minutes active time (65 minutes total including tutorial and survey). ~1 minute per question. Exam tip: Mark uncertain questions, don't spend >2 minutes on any question first pass. |
| 2 | AI-901 passing score and what does scaled scoring mean? | 700/1000 (approximately 70%). Scaled scoring means raw percentage varies—different exam versions are normalized to maintain consistent difficulty. Don't try to calculate raw score during exam. |
| 3 | Multiple-select question strategy on AI-901? | Select EXACTLY the number stated ('Select TWO' = select 2, no more, no less). Selecting wrong count marks entire question wrong even if choices are partially correct. Exam tip: Count your selections before submitting. |
| 4 | Azure AI Language vs Azure OpenAI Service: When to use which? | AI Language: Pre-built NLP (sentiment, entity extraction, intent recognition), faster to deploy, lower cost. OpenAI: Generative tasks (content creation, complex reasoning, conversational AI), requires prompt engineering. Exam tip: Choose AI Language when 'pre-built' or 'minimal development' mentioned. |
| 5 | Azure AI Document Intelligence Layout vs Read: Key difference? | Layout: Extracts text AND structure (tables, checkboxes, sections). Read: Text extraction only (upgraded OCR). Exam tip: Structured forms/documents → Layout. Simple text extraction → Read. |
| 6 | System message vs User message in Azure AI Foundry prompts? | System: Defines AI role, behavior, constraints (set once). User: Actual query/request (changes each interaction). Exam tip: System = persona/rules, User = specific question. |
| 7 | Agent vs Chat application in Azure AI Foundry: When to use agent? | Agent: Needs function calling, multi-step reasoning, external tool integration, orchestration. Chat app: Conversational responses from knowledge base/grounding data only. Exam tip: 'Access external API' or 'call functions' → Agent. |
| 8 | Function calling (tools) in Azure AI Foundry: What must be configured? | Function signature with: name, description, parameters (type, required/optional), return format. Agent decides when to invoke based on user query. Exam tip: Functions enable external data access in agents. |
| 9 | Responsible AI: Map scenario to principle - Model performs worse for certain demographic groups? | Fairness principle violated. First remediation: Evaluate training data for representation gaps and balance dataset. Exam tip: Differential outcomes by demographics = fairness issue. |
| 10 | Responsible AI: Map scenario to principle - User can't understand why loan was denied? | Transparency (explainability) principle violated. Solution: Provide model explanations, feature importance, decision factors. Exam tip: 'Can't understand why' = transparency/explainability. |
| 11 | Azure AI Content Safety vs Azure AI Language PII detection: Difference? | Content Safety: Detects harmful content (hate speech, violence, sexual content, self-harm). PII Detection: Identifies and redacts personal information (names, addresses, account numbers). Exam tip: Harmful content vs private data are different concerns. |
| 12 | Final 10 minutes of AI-901 exam: Best strategy? | Review marked questions, verify multiple-select answer counts (exactly 2 if 'Select TWO'), ensure all questions answered. Don't second-guess confident answers. Exam tip: Unanswered questions are automatically wrong—guess if needed. |
